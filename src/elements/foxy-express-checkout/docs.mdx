# foxy-express-checkout

Custom element that renders express checkout wallet buttons from the checkout
SDK client's API JSON. The element reads supported express checkout
configuration from <code>client.json.express_checkout_options</code> in
<code>@foxy.io/sdk/checkout/client</code> and uses <code>lang</code> as its
only direct input.

Required attributes: none. The checkout SDK client must already be initialized
with API JSON that contains a supported express checkout option. For the
current Stripe-backed flow, the element reads the publishable key from the
express checkout option config in that API JSON.

If the checkout client does not expose a supported express checkout
configuration, the element renders a destructive fallback alert. If Stripe
initializes successfully but reports no wallets for the current browser or
account configuration, the element hides the wallet container rather than
fabricating placeholder buttons.

## Configuration Source

- The element listens to the checkout client from
  <code>@foxy.io/sdk/checkout/client</code>.
- It reads express checkout entries from
  <code>client.json.express_checkout_options</code>.
- For the current Stripe-backed path, it supports the
  <code>stripe-express-checkout-element</code> option and reads the publishable
  key from either <code>config.publishable_key</code> or
  <code>publishable_key</code>.
- If present, Stripe element options are read from
  <code>config.express_checkout_options</code> or
  <code>express_checkout_options</code> on that option payload.

## Behavior Notes

- The element does not emit custom events yet; it currently mirrors the checkout
  placeholder flow by rejecting Stripe confirmation with a not-configured
  message.
- Wallet availability depends on Stripe account setup and the current browser.
  When no wallets are available, the wallet container is hidden.
- Locale resolution uses <code>lang</code> first, then falls back to
  <code>document.documentElement.lang</code>, then to <code>en-US</code>.

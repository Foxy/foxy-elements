# foxy-customer-portal

A drop-in customer portal: sign-in, access recovery, self-registration,
temporary-password reset, and account management.

```html
<foxy-customer-portal store-domain="demo"></foxy-customer-portal>
```

## Attributes

| Attribute             | Required | Default                    | Notes                                                                                               |
| --------------------- | -------- | -------------------------- | --------------------------------------------------------------------------------------------------- |
| `store-domain`        | yes      | —                          | `demo` becomes `demo.foxycart.com`; a value with a dot is used as-is, so custom domains work.       |
| `template-set-id`     | no       | —                          | Reserved for payment methods, which this element does not show yet. Setting it has no effect today. |
| `full-name-template`  | no       | `{first_name} {last_name}` | Plain token substitution, not ICU. Use it for salutations or name order.                            |
| `skip-password-reset` | no       | `false`                    | Suppresses the forced reset screen after signing in with a temporary password.                      |
| `lang`                | no       | `en-US`                    | BCP 47. Underscores are normalised to hyphens.                                                      |

The embed origin is not an attribute — it comes from `VITE_EMBED_ORIGIN` at
build time.

## Events

| Event           | Detail                                 |
| --------------- | -------------------------------------- |
| `signin`        | none                                   |
| `signout`       | none                                   |
| `passwordreset` | `{ result: "skipped" \| "completed" }` |

## Notes

Session data is stored under a key namespaced by store domain, so two Foxy
stores served from one origin do not share a session.

Self-registration appears only when the store enables it. It requires an
hCaptcha challenge, which loads a script from `js.hcaptcha.com`.

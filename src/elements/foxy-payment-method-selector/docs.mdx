# foxy-payment-method-selector

Payment method selector element that renders available checkout payment options, tracks the selected option, and tokenizes the selected method payload.

Required attributes: none. The element still requires checkout client state to be initialized before it can render payment options and tokenize.

For the <code>paypal_platform</code> gateway, the selector renders the base PayPal option plus the SDK-discovered PayPal-supported methods as first-class entries instead of collapsing them into a generic fallback. The standalone PayPal examples live under <code>examples/paypal_platform/</code> with buyer-country pages named <code>us.html</code>, <code>be.html</code>, <code>nl.html</code>, <code>at.html</code>, and <code>pl.html</code>.

For the <code>adyen_embedded</code> gateway, the selector reads the SDK-initialized Adyen Web instance exposed on <code>@foxy.io/sdk/checkout/client</code>, renders one selector entry per available Adyen payment method, and mounts only the selected Adyen Web Component. Calling <code>tokenize()</code> submits the selected Adyen Component and returns <code>&#123;&quot;adyenEmbedded&quot;:&#123;&quot;paymentMethodType&quot;:&quot;...&quot;,&quot;paymentMethod&quot;:&#123;...&#125;,&quot;result&quot;:&#123;...&#125;&#125;&#125;</code>. Adyen Components inherit the selector's shadcn/Tailwind theme through Adyen's documented <code>--adyen-sdk-\*</code> CSS variables, while secured card iframes receive matching font, text, placeholder, and error colors through Adyen's secured-field styles config.

PayPal Pay Later renders a <code>paypal-message</code> element in the option description. The selector only hydrates that element through the PayPal surface already exposed on <code>@foxy.io/sdk/checkout/client</code>; it does not load the PayPal SDK directly. In the standalone example pages, the light-DOM fallback description remains visible unless the shared checkout client already has a hydrated PayPal surface.

Sezzle is exposed as a first-class selector option and <code>tokenize()</code> returns Sezzle metadata for the selected option. The selector does not currently create or start a Sezzle checkout session on its own because the checkout API state only exposes Sezzle's public key, not the checkout payload or checkout URL required to launch the Sezzle flow.

The themed elements in this package support a broader shared set of theme attributes and properties. This page documents only the theme tokens that currently affect <code>foxy-payment-method-selector</code>. Additional shared theme tokens may be accepted for API consistency, but they do not currently change this element.

If checkout state is initialized but exposes no recognized payment methods, the element renders an unavailable state instead of fabricating a fallback option. In that state, <code>tokenize()</code> rejects because no payment method is selected.

## Examples

Run <code>npm run localdev:examples</code> and open the standalone pages under <code>examples/</code>.

- Gateway-named root pages cover the SDK payment gateway ids directly, including <code>authorize.html</code>, <code>authorize_cim.html</code>, <code>braintree_sdk.html</code>, <code>bluesnap.html</code>, <code>cybersource_rest.html</code>, <code>bank_of_america.html</code>, <code>eway.html</code>, <code>firstdata_e4.html</code>, <code>moneris.html</code>, <code>nmi_native.html</code>, <code>paytrace.html</code>, <code>quickbook_payments.html</code>, <code>vantiv_omnipay.html</code>, <code>sagepay.html</code>, <code>stripe_connect.html</code>, <code>stripe_connect_charge.html</code>, <code>stripe_v2.html</code>, <code>authorize_ach.html</code>, <code>ach_com.html</code>, <code>klarna.html</code>, <code>sezzle.default.html</code>, <code>sezzle.custom.html</code>, and <code>mollie_omnipay.html</code>.
- <code>examples/paypal_platform/us.html</code>,<code>be.html</code>,
  <code>nl.html</code>, <code>at.html</code>, and
  <code>pl.html</code> cover the PayPal Platform options by buyer market, and
  their setup notes now live in
  <code>examples/paypal_platform/README.md</code>.
- <code>examples/adyen_embedded/us.html</code>, <code>nl.html</code>,
  <code>be.html</code>, and <code>pl.html</code> cover Adyen Embedded with real
  Sessions data.
- <code>examples/uninitialized.html</code> shows the empty client state.

Stripe examples read <code>VITE_STRIPE_PUBLISHABLE_KEY</code> first and fall back to <code>VITE_STRIPE_DEMO_PUBLISHABLE_KEY</code> or a safe demo key. The PayPal country pages under <code>examples/paypal_platform/</code> use matching sandbox client IDs: <code>us.html</code> reads <code>VITE_PAYPAL_SANDBOX_CLIENT_ID_US</code>, <code>be.html</code> reads <code>VITE_PAYPAL_SANDBOX_CLIENT_ID_BE</code>, <code>nl.html</code> reads <code>VITE_PAYPAL_SANDBOX_CLIENT_ID_NL</code>, <code>at.html</code> reads <code>VITE_PAYPAL_SANDBOX_CLIENT_ID_AT</code>, and <code>pl.html</code> reads <code>VITE_PAYPAL_SANDBOX_CLIENT_ID_PL</code>. Each page seeds the matching locale, currency, and buyer-country hint. The per-market setup details and expected methods live in <code>examples/paypal_platform/README.md</code>. Adyen Embedded examples under <code>examples/adyen_embedded/</code> require real Adyen Session env vars and render only methods returned by Adyen for that session. Sezzle examples read <code>VITE_SEZZLE_PUBLIC_KEY</code>; without a real sandbox key the Sezzle SDK loads but renders in an unauthenticated state. The Sezzle example is split into <code>sezzle.default.html</code> and <code>sezzle.custom.html</code> — one button per page — because the Sezzle SDK instance is a singleton per public key and <code>sdk.init()</code> must only be called once per instance.

The standard card, Stripe, and PayPal example pages also seed a single saved payment method through <code>saved_payment_methods</code> so each supported example can demonstrate the saved-card option alongside the gateway-specific flow.

## Tokenization Payload

<code>tokenize()</code> resolves with one of these payload types. The
<code>tokenizationsuccess</code> event emits the same object as
<code>event.detail.payload</code>.

```ts
type PaymentMethodSelectorSavedCardTokenizePayload = {
  token: string | undefined;
  requestId: string | undefined;
  cardBrand: string | undefined;
  last4: string | undefined;
  expirationMonth: number | undefined;
  expirationYear: number | undefined;
};

type PaymentMethodSelectorNewCardTokenizePayload = {
  token: string;
  requestId: string;
  cardBrand: string | undefined;
  last4: string | undefined;
  expirationMonth: number | undefined;
  expirationYear: number | undefined;
};

type PaymentMethodSelectorAchTokenizePayload = {
  token: string;
  requestId: string;
};

type PaymentMethodSelectorStripeCardElementTokenizePayload = {
  paymentMethodId: string;
  cardBrand: string | undefined;
  last4: string | undefined;
  expirationMonth: number | undefined;
  expirationYear: number | undefined;
};

type PaymentMethodSelectorStripePaymentElementTokenizePayload = {
  paymentMethodId: string;
  paymentMethodType: string;
  cardBrand?: string;
  last4?: string;
  expirationMonth?: number;
  expirationYear?: number;
};

type PaymentMethodSelectorPurchaseOrderTokenizePayload = {
  purchaseOrderNumber: string;
};

type PaymentMethodSelectorPayPalPlatformTokenizePayload = {
  paypalPlatform: {
    clientId: string;
    flow: "buttons" | "card-fields" | "apple-pay" | "google-pay";
    fundingSources?: (
      | "paypal"
      | "paylater"
      | "credit"
      | "venmo"
      | "sepa"
      | "bancontact"
      | "eps"
      | "blik"
      | "ideal"
      | "p24"
    )[];
  };
};

type PaymentMethodSelectorApplePayTokenizePayload = Record<string, never>;
type PaymentMethodSelectorGooglePayTokenizePayload = Record<string, never>;
type PaymentMethodSelectorGenericTokenizePayload = Record<string, never>;

type PaymentMethodSelectorTokenizePayload =
  | PaymentMethodSelectorSavedCardTokenizePayload
  | PaymentMethodSelectorNewCardTokenizePayload
  | PaymentMethodSelectorAchTokenizePayload
  | PaymentMethodSelectorStripeCardElementTokenizePayload
  | PaymentMethodSelectorStripePaymentElementTokenizePayload
  | PaymentMethodSelectorPurchaseOrderTokenizePayload
  | PaymentMethodSelectorPayPalPlatformTokenizePayload
  | PaymentMethodSelectorApplePayTokenizePayload
  | PaymentMethodSelectorGooglePayTokenizePayload
  | PaymentMethodSelectorGenericTokenizePayload;
```

Billing address edits are sent directly to the checkout client through

<code>updateBillingAddress(...)</code> as fields change. They are not included
in the tokenization payload.

Purchase order selections render a single required purchase order number field.
The selector enforces a 32-character maximum and returns the entered value in
the tokenization payload.

PayPal Platform selections return <code>paypalPlatform</code> metadata that identifies the selected PayPal flow. Wallet and alternative payment methods use <code>flow: "buttons"</code> with a single funding source, while PayPal new-card, Apple Pay, and Google Pay use their dedicated flow values.

## Usage Example

```html
<foxy-payment-method-selector
  id="payment-selector"
  lang="en-US"
  option-index="0"
  theme-primary="#111827"
  theme-radius="0.75rem"
></foxy-payment-method-selector>

<button type="button" id="selector-tokenize">Tokenize Selection</button>

<script type="module">
  import "https://cdn-js.foxy.io/elements@2/foxy-payment-method-selector.js";
  import { client as checkoutClient } from "@foxy.io/sdk/checkout/client";

  const selector = document.querySelector("#payment-selector");
  const selectorTokenizeButton = document.querySelector("#selector-tokenize");

  await checkoutClient.refresh();

  selector.addEventListener("tokenizationsuccess", (event) => {
    console.log("Payment method tokenized", event.detail.payload);
  });

  selector.addEventListener("tokenizationerror", (event) => {
    console.error("Payment method tokenization failed", event.detail.error);
  });

  selectorTokenizeButton.addEventListener("click", async () => {
    const payload = await selector.tokenize();
    console.log("Selector tokenize() result", payload);
  });
</script>
```
